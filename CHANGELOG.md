# Changelog

All notable changes to Passaver. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [1.3.0] - 2026-11-03

### Added

- **Guided fixes.** The Fix button opens a site's change-password page through the standard `/.well-known/change-password` address. Passaver then offers a strong password on the form and updates the saved login when you save the change. If the new password was generated by Passaver, the update happens automatically, and Undo restores the old password.
- **Password health card** in the Vault, with plain-language advice on what to fix first. Issue filters list the logins that need attention, worst first, each with a Fix button.
- The editor explains each problem it finds (weak, reused, old, not HTTPS) and offers the guided fix.
- Site icons: the site's own favicon when the browser has one, otherwise a monogram with a colour that stays the same for each site.

### Changed

- The popup now works like an app: the header, search and bottom bar stay in place, and only the content scrolls.
- The reuse warning names the exact hosts that share the password.
- The README has a banner, screenshots that follow GitHub's light or dark theme, diagrams, an FAQ and a section on who Passaver is for.

### Fixed

- Pressing **Save** on one subdomain no longer overwrites a login with the same username on another subdomain of the same site. A new login made in the editor follows the same rule. Version 1.2.1 had fixed this for the save prompt but not for these two paths.
- Status tags no longer wrap inside their pill on long host names.

## [1.2.1] - 2026-11-03

### Security

- A login fills automatically (keyboard shortcut, or Enter in the popup) only on the exact host where it was saved. Logins from sibling hosts of the same site are offered only with their host named.
- Signing in on one host no longer prompts to update another host's saved password.
- Common shared-hosting domains (such as `onrender.com`, `workers.dev` and `myshopify.com`) treat each customer subdomain as its own site.

## [1.2.0] - 2026-11-03

First public release.

### Added

- Vault encrypted with AES-256-GCM, with its key sealed to the PC and Windows account by DPAPI.
- One-click fill, saving as you sign in, and support for two-step logins and change-password forms.
- Generated-password history, strong-password suggestions on sign-up forms, and automatic saving of new accounts.
- Vault health score, optional PIN with auto-lock, and a privacy scan that keeps personal data out of the repository.
